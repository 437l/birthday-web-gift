How to Change Style

Go to style.css, then edit the :root variables.

Example:

:root {
  --primary-color: #ff0062;
  --secondary-color: #ff79b9;
}

⸻

How to Add a Gallery

Edit gallery.js file:

const galleryData = {
  people: [
    {
      name: "Name",
      caption: "Message here",
      image: "image-url"
    }
  ]
};

Add or remove items inside the people array.
